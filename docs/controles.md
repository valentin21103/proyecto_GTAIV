# Controles

| Tecla | Acción | Mod |
|---|---|---|
| `X` (mantener) cerca de alguien | Menú de interacción | Greet-Taunt-Rob |
| `1` / `2` / `3` / `4` | Saludar / Provocar / Robar / Vender-comprar | Greet-Taunt-Rob |
| Clic derecho | Robar a punta de pistola | Greet-Taunt-Rob |
| `1` `2` `3` / `5` (menú dealer) | Comprar cocaína / heroína / pastillas / robar | Pusher |
| `K` / `J` | Aceptar / rechazar multa | Stop Right There |
| `L` (manejando) | Guardar auto en Mis autos | MisAutos |
| `L` (a pie) | Lista de autos: flechas, `Enter` pedir, `Supr` borrar | MisAutos |
| `E` (a pie, cerca de un auto o estación) | Menú: cargar nafta, comprar / usar bidón, abrir baúl (parado atrás de tu auto activo). `E` cierra el menú y corta la carga | MisAutos |
| `U` (tocar) | Usar la curación que más sirve (gasa si sangrás) | VidaNiko |
| `U` (mantener) | Rueda de objetos (curaciones, comida, bebida, cigarrillos) y estado de Niko (hambre, sed, baño, salud): mouse o flechas y soltar | VidaNiko |
| `U` (en tu auto, parado) | Guantera: hasta 3 bebidas; Enter tomar / guardar, Retroceso sacar | VidaNiko + MisAutos |
| `U` (fumando) | Apagar el cigarrillo: a pie lo pisa, en el auto lo tira por la ventana (se puede caminar y manejar fumando) | VidaNiko |
| `E` (en un patrullero parado) | Computadora de la policia, tambien en los patrulleros que agrega el mod de autos | VidaNiko |
| `J` (con arma de fuego, alguien pegado adelante) | Culatazo: le saca vida y lo tira un momento | Culatazo |
| `E` (mirando al empleado) | Hablar con el empleado y comprar: farmacia = curaciones + agua; restaurante = comida y bebida; almacén = bebidas, snacks y cigarrillos | VidaNiko |
| `E` (estación de servicio) | Tienda de autoservicio: de todo | VidaNiko |
| `Ctrl+F8` | Menú para registrar el lugar actual como farmacia, restaurante, almacén o baño (tu casa) (`scripts/Lugares.ini`) | VidaNiko |
| `Ctrl+F9` | Registrar farmacia directo | VidaNiko |
| `Z` | Sentarse (de espaldas al banco); `Z` o `W` para pararse. Sentado comés y tomás sentado | VidaNiko |
| `E` (frente a una computadora, adentro) | Usar la computadora (abre el escritorio del juego aunque la partida tenga el monitor sin script) | VidaNiko |
| `Ctrl+F6` / `Ctrl+Shift+F6` | Diagnóstico de la computadora del cibercafé / destrabar: re-registra las computadoras en la partida, libera el menú de pausa, el control y el minijuego. Se arregla solo si te parás 4 s frente a una computadora que no responde | VidaNiko |
| `N` (tocar) | Orinar: vacía la vejiga y la comida te llena x1.25 por 10 min | VidaNiko |
| `N` (mantener, cerca de un baño) | Ir de cuerpo (pantalla a negro). Sirve en bares, restaurantes, tiendas, estaciones, baños químicos o un baño registrado: vacía el intestino y la comida te llena x1.5 por 15 min | VidaNiko |
| `I` (manejando) | Apagar / prender motor y luces | MotorAuto |
| `Shift+B` / `Shift+N` / `Shift+M` | Arma siguiente / anterior / agarrar | ArmasRapidas |
| `F1` | Una pistola / dos pistolas | Double Homicide |
| `F11` | Aspecto de Niko | NikoLook |
| `G` | Tirar el arma (rueda de armas, antes E) | IV_Weapon_Wheel |
| `H` | Cambiar de hombro al apuntar (antes E) | ProperCoverandDrive-By |
| `Ctrl+F5` | Menú de primera persona (antes Ctrl+F8) | FirstPersonCutscene |
| `Tab` | Rueda de armas | IV Weapon Wheel |
| `Q` (en auto) | Rueda de radio | IV Weapon Wheel |
| `F6` | Flechas de pandillas | ActivitiesPlus |
| `F7` / `V` | Primera persona / cambiar cámara | First Person Overhaul |
