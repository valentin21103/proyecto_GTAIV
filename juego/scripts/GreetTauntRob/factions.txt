# Decides the name shown under the menu when you hold LT on an NPC. Anything that matches no line shows "Stranger".
#
# Two kinds of lines:
#     PEDTYPE = Name            matches the NPC's ped type (underscores and capitals are ignored)
#     model:MODELNAME = Name    matches one specific ped model (use this for hookers, dealers, etc.)
#
# A model line beats a ped type line. For ped types, an exact match wins, otherwise the first line whose
# text appears inside the ped type is used, so put more specific lines above general ones.
#
# After locking on, scripts\StrangerSystem.log shows what the script saw, for example:
#     Locked on ped type 'Gang_RussianGang', model hash 123456 -> menu name 'Stranger' (no rule)
# If a name is wrong, fix the line here. Changes are read when the game starts.
